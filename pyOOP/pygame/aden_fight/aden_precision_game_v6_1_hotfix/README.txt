Aden's Needle Trial v6.1 Hotfix
===============================

v6.1 수정 사항
--------------
- 실행 즉시 발생하던 NameError: name 'Enemy' is not defined 오류 수정
- ChaserEnemy와 SkeletonHunter 클래스가 Enemy 클래스보다 먼저 정의되던 순서 문제 수정
- 기존 v6 Nightmare Expansion 기능은 그대로 유지

중요
----
기존 v6 폴더에서 실행하지 말고, 이 v6.1 zip을 새 폴더에 압축 해제한 뒤 main.py를 실행하세요.

Aden's Needle Trial v6 - Nightmare Expansion
============================================

핵심 변경점
-----------
- 31~50단계를 슈퍼 점프 기반 괴랄 맵으로 재설계
- 최종 보스는 50단계 이후 51단계에서 등장
- 최종 보스 Void Nightmare 난이도 강화
- 위/아래로 움직이는 뾰족한 창 추가: V
- 좌/우에서 튀어나오는 가시 추가: <, >
- 유저를 추격하며 총알을 발사하는 괴물 추가: H
- 1분 동안 아무 행동이 없으면 강력한 해골 몬스터 Skeleton Hunter 등장
- 해골 몬스터 체력 100
- 해골 몬스터 처치 시 “그 힘이야말로 진정한 남자다” 문구 출력
- 프롤로그 추가
- 시작 전 플레이어 이름 입력 추가
- 클리어 후 통계/랭킹/칭호 화면 추가

통계 화면에 표시되는 항목
-----------------------
- 이름
- 칭호
- 플레이타임
- 사망 횟수
- 처치한 적 수
- 발사한 총알 수
- 점프 횟수
- 대시 횟수
- 차지 점프 횟수
- 입은 데미지

조작법
------
- 이동: ← / → 또는 A / D
- 일반 점프: Z / Space / W / ↑ 짧게 누르고 떼기
- 슈퍼 점프: Z / Space / W / ↑ 꾹 누른 뒤 떼기
- 대시: Shift 또는 C
- 원거리 공격: X 또는 J
- 체크포인트 재시작: R
- 종료: ESC

맵 문자
-------
. = 빈 공간
# = 일반 발판
B = 무너지는 발판
^ = 고정 가시
! = 튀어나오는 가시
L = 수직 레이저
V = 위/아래로 움직이는 창
< = 왼쪽에서 튀어나오는 가시
> = 오른쪽에서 튀어나오는 가시
P = 시작 위치
C = 체크포인트
O = 포탈
E = 워커 적
S = 슈터 적
H = 추격 슈터
M = 중간 보스
Y = 최종 보스 Void Nightmare

실행
----
python -m pip install pygame
python main.py
