Aden's Needle Trial v4
======================

이번 버전의 핵심 수정 사항
-------------------------
1. 무너지는 발판 소프트락 문제 수정
   - 기존에는 B 발판이 한 번 무너지면 다시 생성되지 않았습니다.
   - 이제 사망하거나 R로 체크포인트 재시작을 하면 현재 스테이지의 동적 오브젝트가 다시 로드됩니다.
   - 따라서 무너지는 발판을 한 번에 통과하지 못해도 다시 도전할 수 있습니다.

2. 난이도 강화
   - 갑자기 튀어나오는 가시 추가
   - 갑자기 켜지는 수직 레이저 추가
   - 21단계 이후 후반부 맵에는 더 많은 함정이 배치되어 있습니다.

3. 배경음악 추가
   - 1~20단계: Red Shift
   - 21단계 중간 보스: City of the Wolf
   - 22~30단계: False Vacuum Decay
   - 31단계 최종 보스: Final Boss Battle

4. 기존 v3 내용 유지
   - 21단계 강화 보스 Needle Warden
   - 22~30단계 고난도 후반부
   - 31단계 최종 보스 Void Heart
   - 최종 보스 클리어 후 aden과 여자친구가 만나는 엔딩 컷신

실행 방법
---------
1. Python 설치
2. pygame 설치
   python -m pip install pygame
3. 실행
   python main.py

조작법
------
- 이동: ← / → 또는 A / D
- 점프: Z / Space / W / ↑
- 대시: Shift 또는 C
- 원거리 공격: X 또는 J
- 체크포인트 재시작: R
- 종료: ESC

맵 문자 규칙
------------
. = 빈 공간
# = 일반 발판
B = 무너지는 발판
^ = 고정 가시
! = 가까이 가면 갑자기 튀어나오는 가시
L = 갑자기 켜지는 수직 레이저
P = 플레이어 시작 위치
C = 체크포인트
O = 다음 단계 포탈
E = 워커형 적
S = 슈터형 적
K = 기존 보스
M = 21단계 보스 Needle Warden
Z = 최종 보스 Void Heart

스테이지 구성
-------------
- 1~20단계: 기존 챕터 + 일부 기습 함정 추가
- 21단계: Needle Warden 중간 보스
- 22~30단계: 고난도 후반부 맵
- 31단계: Void Heart 최종 보스
- 최종 보스 클리어 후 엔딩 컷신

보스전 규칙
-----------
보스가 살아있으면 포탈에 닿아도 다음 단계로 넘어가지 않습니다.
보스를 먼저 처치해야 포탈이 작동합니다.

주의
----
음악 재생은 pygame.mixer를 사용합니다.
사용 환경에서 오디오 장치가 비활성화되어 있으면 게임은 계속 실행되지만 음악만 나오지 않을 수 있습니다.
