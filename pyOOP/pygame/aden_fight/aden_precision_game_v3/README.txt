Aden's Needle Trial v3
======================

이번 버전의 핵심 변경점
----------------------
- 21단계에 강화 보스전 추가: Needle Warden
- 22~30단계를 후반부 고난도 챕터로 추가
- 30단계 클리어 후 최종 보스전으로 진입
- 31단계 최종 보스 추가: Void Heart
- 최종 보스 클리어 후 엔딩 컷신 추가
  - aden이 여자친구와 무사히 만나 데이트하러 가는 장면
- 보스 애니메이션 추가
  - Needle Warden 8프레임
  - Void Heart 10프레임
- 여자친구 도트 캐릭터 추가
- 원거리 공격 유지
- 보스 패턴 강화
  - 조준탄
  - 회전탄
  - 탄막 링
  - 가로 탄막
  - 체력에 따른 페이즈 변화

실행 방법
---------
1. Python 설치
2. pygame 설치
   python -m pip install pygame
3. 실행
   python main.py

조작법
------
- 이동: ← / → 또는 A / D
- 점프: Z / Space / W / ↑
- 대시: Shift 또는 C
- 원거리 공격: X 또는 J
- 체크포인트 재시작: R
- 종료: ESC

스테이지 구성
-------------
- 1~20단계: 기존 챕터
- 21단계: Needle Warden 보스전
- 22~30단계: 고난도 후반부 맵
- 31단계: Void Heart 최종 보스전
- 최종 보스 클리어 후 엔딩 컷신

맵 문자 규칙
------------
. = 빈 공간
# = 일반 발판
B = 무너지는 발판
^ = 가시
P = 플레이어 시작 위치
C = 체크포인트
O = 다음 단계 포탈
E = 워커형 적
S = 슈터형 적
K = 기존 보스
M = 21단계 보스 Needle Warden
Z = 최종 보스 Void Heart

맵 추가 방법
------------
1. levels 폴더에서 기존 level_XX.txt 파일을 복사합니다.
2. level_32.txt처럼 다음 번호로 이름을 바꿉니다.
3. 위 문자 규칙에 맞게 텍스트 맵을 수정합니다.
4. 게임은 level_*.txt 파일을 이름순으로 자동 로드합니다.

보스전 규칙
-----------
보스가 살아있으면 포탈에 닿아도 다음 단계로 넘어가지 않습니다.
보스를 먼저 처치해야 포탈이 작동합니다.

주의
----
21단계 이후는 일부러 난이도를 크게 올린 후반부 챕터입니다.
아이워너류 느낌을 살리기 위해 가시, 무너지는 블록, 슈터, 좁은 발판을 많이 배치했습니다.
