Aden's Needle Trial v2
======================

이번 버전의 변경점
------------------
- 작은 골 지점 G 대신 큰 애니메이션 포탈 O를 사용합니다.
- 원거리 공격을 추가했습니다.
- 보스 스테이지를 추가했습니다. 20스테이지에서 보스를 처치해야 포탈이 작동합니다.
- aden 캐릭터 애니메이션을 개선했습니다.
  - idle 2프레임
  - run 4프레임
  - jump
  - fall
  - dash
  - shoot
- 기존 근접 슬래시 대신 원거리 탄환 방식으로 변경했습니다.
- 적 탄환도 aden의 탄환으로 지울 수 있습니다.

실행 방법
---------
1. Python 설치
2. pygame 설치
   python -m pip install pygame
3. 실행
   python main.py

조작법
------
- 이동: ← / → 또는 A / D
- 점프: Z / Space / W / ↑
- 대시: Shift 또는 C
- 원거리 공격: X 또는 J
- 체크포인트 재시작: R
- 종료: ESC

맵 파일 구조
------------
levels 폴더 안의 level_01.txt ~ level_20.txt 파일을 읽습니다.

맵 문자 규칙
------------
. = 빈 공간
# = 일반 발판
B = 무너지는 발판
^ = 가시
P = 플레이어 시작 위치
C = 체크포인트
O = 다음 단계 포탈
E = 워커형 적
S = 슈터형 적
K = 보스

맵 추가 방법
------------
1. levels 폴더에서 level_20.txt 같은 파일을 복사합니다.
2. level_21.txt로 이름을 바꿉니다.
3. 텍스트 맵을 수정합니다.
4. 게임을 실행하면 level_*.txt 파일을 순서대로 자동 로드합니다.

주의
----
20스테이지는 보스전입니다.
보스가 살아있으면 포탈에 닿아도 다음으로 넘어가지 않습니다.
