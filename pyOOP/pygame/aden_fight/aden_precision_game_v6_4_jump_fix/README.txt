Aden's Needle Trial v6.4 - Jump Fix
===================================

v6.4 수정 사항
--------------
- 차지 점프 때문에 점프 반응이 느리던 문제 수정
- 이제 점프 키를 누르는 순간 즉시 일반 점프가 발동됩니다.
- 점프 키를 계속 누르고 있으면 공중에서 추가 상승 보정이 들어갑니다.
- 키를 오래 누르면 슈퍼 점프로 집계됩니다.
- 즉, 정밀 플랫포머에 필요한 즉각적인 점프 반응을 유지하면서 높은 점프도 가능합니다.

조작법
------
- 점프: Z / Space / W / ↑ 누르는 순간 즉시 점프
- 더 높게 점프: 점프 키를 계속 누르고 있기
- 대시: Shift 또는 C
- 원거리 공격: X 또는 J
- 체크포인트 재시작: R
- 종료: ESC
